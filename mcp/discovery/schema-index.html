JSON Schemas

JSON Schema draft 2020-12 for every record kind in the open data dumps and the MCP results. Licence: CC BY 4.0.

clip.jsonClip (a talk or a passage of one)
A playable talk on an official upload.
collection.jsonCollection
An editorial or user-made grouping.
common.jsonWiser common definitions
curation.jsonUser curation or essay
User-authored.
edge.jsonLineage / relation edge
A directed, sourced relation.
event.jsonEvent
A dated happening: historical (a council, a founding) or upcoming (a retreat run, a live session).
person.jsonPerson (teacher, scholar or figure)
One human (or a personified source such as Hermes Trismegistus).
place.jsonPlace
A monastery, centre, ashram, retreat house, pilgrimage site or lodge.
practice.jsonPractice
Something you do, not watch.
profile.jsonPractitioner profile (export shape)
What a user owns and can export (GET /me/export).
text.jsonText (scripture, treatise, book, essay)
A work.
topic.jsonTopic
A question people bring, seen across traditions.
tradition.jsonTradition / school / lineage node
A node of the tradition tree.

For agents and developers
