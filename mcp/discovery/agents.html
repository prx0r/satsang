SATSANG

For agents and developers

Satsang is an open, citable directory of the wisdom traditions. Ask ChatGPT, Claude or your own agent about traditions, teachers, lineages, retreats and free texts, and get answers that link back to a page here and to the original source.

Connector URL

https://mcp.tantrafiles.xyz/mcp

No sign-in. Read-only. Streamable HTTP (MCP 2025-06-18, 2025-03-26, 2024-11-05); legacy SSE at https://mcp.tantrafiles.xyz/sse.

Add it to ChatGPT

  1. Settings → Apps & Connectors → Advanced → turn on Developer mode (Plus, Pro, Business, Enterprise or Edu).
  2. Connectors → Create: name Satsang, URL https://mcp.tantrafiles.xyz/mcp, Authentication No authentication.
  3. In a chat, open the tools menu, enable Satsang, and ask e.g. “Find residential Theravada retreats in the UK with contact pages”. Deep research can use its search and fetch tools.

Custom GPT instead: Configure → Actions → Import from URL https://mcp.tantrafiles.xyz/openapi.json, authentication None.

Add it to Claude

  1. Claude.ai or Claude Desktop: Settings → Connectors → Add custom connector → URL https://mcp.tantrafiles.xyz/mcp.
  2. Claude Code: claude mcp add --transport http satsang https://mcp.tantrafiles.xyz/mcp
  3. Other clients (Cursor, VS Code, MCP Inspector): server type HTTP/streamable, same URL.

REST and data

  • OpenAPI 3.1: https://mcp.tantrafiles.xyz/openapi.json · e.g. /api/places?tradition=theravada&country=GB&offers=residential, /api/study/thai-forest, /api/lineage/path
  • Bulk data: /data/index.json (JSON, JSONL, JSON-LD per kind, with checksums) and JSON Schemas
  • Summaries for language models: /llms.txt, /llms-full.txt; server card: /.well-known/mcp.json

What is in it

178 traditions and schools · 727 people · 1,122 lineage links · 875 places in 51 countries · 407 texts and books (115 free) · 85 practices · 68 topics · 9,986 talks. Built 2026-10-24.

Every answer carries url (the page to cite), source_url, verified_on and confidence. Contacts are shown only as each place publishes them; please do not use them for bulk mail. Programme dates change: follow the place’s schedule link.
