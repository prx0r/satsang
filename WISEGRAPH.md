# Wisegraph

Wiser's knowledge graph of traditions, people and texts: the Funnier "funnygraph" for wisdom traditions. Source of truth:
`work/wiser/app/wisegraph/*.json` (hand-curated, reviewed). Published to the site as `site/data/wisegraph/wise.json`
(profiles) plus the older `boards.json / profiles.json / graph.json` (charts), and to D1 via `wisegraph/seed.sql`.

## Files
| file | what |
|---|---|
| `traditions.json` | `nodes[]`: `{id, label, kind: family|school|lineage, parent, wikidata, blurb}`. A tree: family > school > lineage. The family is the site's tradition filter (`clip.region`). |
| `people.json` | `people[]`: `{id, name, short?, kind: speaker|figure|text, tradition (most specific node), wikidata, years, bio, tagline?, aliases[], channels[]?, links{}?, works[]}`. `works[]`: `{id, title, year?, kind: book|text|talk series|retreat|talk}` (the "specials"). |
| `edges.json` | `edges[]`: `{from, to, type, conf: high|medium, note?}`. Types: `teacher_of` (person → student), `influenced` (person/tradition → person/tradition), `lineage_of` (person/text → the tradition they found or define), `studied_with` (looser, medium-confidence; shown as "Studied with", never heir). People may carry `living: true` (no death date on Wikidata, uncontradicted). |
| `portraits.json` | built by `tools/portraits.py`: `{personId: {file, thumb (≈800 px), face (≈250 px), w, h, page, artist, license, licenseUrl, source}}`. Wikidata P18 → Commons; PD / CC0 / CC BY / CC BY-SA only. |
| `topic-takes.json` | `topics{topicId: {order[traditionId], takes{traditionId: one line}}}`. Wiser's own summary of each tradition's classic position, for `#topic/<id>`. |
| `places.json` | generated by `tools/merge-sources.py` from `sources/places`: places (+ retreats, countries). `teachers` = founders / historically tied. |
| `place-contacts.json` | generated by `tools/place-contacts.py`: public contacts as published on official sites, with source_url + checked. |
| `seed.sql` | generated: `wg_traditions, wg_people, wg_works, wg_edges, wg_clip_links` (D1, migration 0012). |

## Kinds
- **speaker**: appears on video in talks we embed. Profile shows Talks by / Full talks.
- **figure**: no footage we use; met through talks ABOUT them (`clip.figures[]`, matched by `aliases` on title +
  description, and on 4+ transcript mentions internally). Profile shows Talks about.
- **text**: a scripture or corpus (Bardo Thödol, Shiva Sutras, Nag Hammadi). Same as a figure.

## How a page reads the graph (`src/wise.js`)
- Tradition chips = the person's node and its ancestors. Lineage tree = the whole family subtree.
- Influenced by = edges into the node (`teacher_of`, `influenced`); Influenced = edges out. Tradition nodes appear too.
- For seekers of = `tools/build-wise.py kin()`: direct edge 1.0, same node 0.6, same school 0.4, same family 0.25, +0.3
  when a tradition that influenced one contains the other; top 8 with kin ≥ 0.25.
- Topic columns: each talk sits under the first `order` node that is an ancestor of the speaker's tradition, else its
  school. Columns in `order` with no talks show the take line and "Talks arriving".

## Adding people / traditions (the sourcing integration)
1. Merge `sources/<group>/people-additions.json`, `traditions-additions.json`, `edges-additions.json` into the three
   files (same shapes; keep ids lowercase-hyphen; `tradition` must exist in traditions.json).
2. `python3 tools/build-clips.py ../raw ../transcripts-internal` (or the clip build that takes the candidates), then
   `python3 tools/portraits.py` and `python3 tools/build-wise.py`, then `sh deploy.sh`.
3. Optional: `wrangler d1 execute wiser --remote --file ../wisegraph/seed.sql` from `api/`.
