# 43 — Trika prep week (autonomous foundation for Abhinavagupta + VBT)

**What:** the first pinnacle-backwards syllabus — seven days of safe,
teacher-free foundation (steady breath, the turn of the breath, recognition)
for later Tantrasara and VBT work. Reuses two existing deep-tantra practices
by id, adds one new foundation practice, one deitybody visual, one journey.

**Why this shape:** prep stays autonomous and loggable; anything initiated,
retentive, or mantra-given stays orientation-only in deep-tantra and is never
duplicated here. The journey ends by pointing at a teacher, not replacing one.

reads it natively) + `visuals/gap-rest.json` (deitybody-v1) +
`collection-addition.json` (trika-prep-week journey) + REPORT + MERGE-NOTES.
