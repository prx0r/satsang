# 52 — Nibbana arguments (the logical chain)

**What:** the logical arguments for nibbana, working backwards from the
conclusion to premises verifiable in direct experience. 10 arguments,
each with: what it claims, what it depends on, the evidence (sutta +
Analayo parallel + Nanananda), the counter-argument, and the direct
experience test. Plus the whole argument in one paragraph, and a
6-rung direct experience ladder.

**This is the scaffolding that makes the movie possible.** Every line of
narration traces to a premise that leads to an experience. Source:
Nanananda Sermons 1-33 + Analayo analysis + Pali parallels.

**The chain in one line each:**
nibbana = what remains when fabrications stop → what remains when craving
stops → craving is conditioned → craving arises from the chain → the
chain is built from name-and-form → name-and-form builds the self → the
self is a designation → everything is dependent → existence depends on
grasping → grasping is craving → craving is the fuel → the fire going
out is nibbana → and you have already experienced it.
