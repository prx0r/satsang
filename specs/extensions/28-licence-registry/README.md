# 28 — Licence registry + Dhamma books (availability ≠ licence)

**What:** the per-website licence registry the user asked about — with the
rule that settles it: licence lives INSIDE each book (copyright page),
sites get defaults with evidence, books override. Plus the first
licence-carrying text records (Amaro, Thanissaro, Maha Boowa).

**Files:** licence-sources.json (7 domains with terms evidence), texts
(3 books with licence + verified links), REPORT with the correction,
MERGE-NOTES.

**The correction (read REPORT):** a PDF on a website is NOT public access
in the rights sense. Dhamma books are free-to-distribute under specific
licences (gift-of-dhamma custom, CC BY-NC, monastery free-reprint) —
generous, but they forbid sale and mutilation, and Dyczkowski's paid
courses are fully copyrighted. Free to read ≠ free to reuse.
