# 46 — Nibbāna path (the removal chain)

**What:** a dependency graph of fabrications to see through, in the order
Ñāṇananda, Ñāṇavīra, and Anālayo teach them. Nibbāna is not a node — it
is what remains when all nodes are seen through. The runtime walks the
user through the chain, tracking progress behaviourally.

**The insight:** nibbāna is not something you attain. It is what is left
when you stop fabricating. The mind builds signs (concepts, labels,
categories). When the signs stop, what remains was always there.

**The chain:** stable attention → body awareness → identity view → doubt
→ attachment to rites → sensual desire → ill-will → form craving →
formless craving → concept-making → the observer → time → nibbāna.

**Files:** `nibbana-path.md` (the graph + runtime spec, JSON embedded in
markdown) + REPORT + MERGE-NOTES.
