# 14 — Lineage clusters (Trika pilot + builder)

**What:** the cluster unit the user asked for — one tradition, complete:
members, dharma chains, academic chains, texts, practices, places, orphans,
and the inception trace back to the root. `cluster.py` builds it for any
tradition subtree; `clusters/trika.json` is the pilot; `clusters/thai-forest.json`
validates the pattern; `trika-inception.md` / `thai-inception.md` are the
readable traces; `fixes/living-flags.json` corrects 13 missing living flags.

**Merge:** MERGE-NOTES.md (flags hand-merge + builder to validate/ + docs
beside GOLDEN-PATH). Builder output is validated by construction; the
runtime's dialect gate accepts `clusters/` output as a known kind.
