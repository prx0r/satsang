# RETREAT-BUILDER (2026-10-20)

The loop, end to end. Each stage feeds the next; nothing is mandatory
except honesty about what stage you're in.

## 1. Intent → plan (`plan_retreat`)

Inputs: topic + days + strictness (+ tradition/teacher optional).
The planner: (a) matches talks — topic pool, MMR across traditions so a
jhana retreat hears wood, sutta and Burmese voices, full talks only, teacher
filter narrows; (b) scales a timetable skeleton (33 shapes) to strictness
hours; (c) layers rules (strictness base + tradition overlay); (d) writes
flexibility notes ("shorten sits to 30m before dropping them", "a missed
day restarts the day, never the retreat"). Output is a plan, not a booking.

## 2. Personalize

Swap talks (same topic, any tradition), shift wake ±1h, mark workdays
(shorter blocks auto-fill). Every change re-checks the container (min
2 sits + 1 talk + silence window, or it warns "this is a study week, not
a retreat" — honest labels).

## 3. Execute + notes

Timer blocks per 33; evening prompt (three lines: what sat / what stuck /
question for a teacher); uploads attach to days. Teacher-prompt cards
accumulate with contacts attached.

## 4. Keepsake (retreat-log.json)

Plan + kept blocks + talks heard + notes + stats + prompts. Private by
default. Export = JSON + printable page. The keepsake is the product of a
solo retreat; it asks for nothing and proves nothing beyond itself.

## 5. Share → curations

Publish (minus private notes) as a curation: timetable + talk list + rules
others clone. Clones reference talks, never copy. Counts as a Collection
kind journey for progress + reminders (ROADMAP 12 machinery).

## 6. Go live → rooms

Promote to a hosted room (35): dates, RSVPs, live sits. The host inherits
the timetable; participants get their own keepsakes. Solo → shared in one tap.
