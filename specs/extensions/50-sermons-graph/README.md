# 50 — Sermons graph (everything Ñāṇananda describes)

**What:** the complete conceptual map of the 33 sermons. Every concept
modelled: what it is, what it depends on, what depends on it, the practice
that sees through it, the visual form. This is the data layer that drives
the game (pack 47), the visuals (pack 49), and the practice system
(packs 43-45).

**The graph:** 18 concepts, three dependency chains, six sermon ranges
mapped to visuals. From avijjā (ignorance, the root) through the twelve
links through nimitta and papañca to animitta and nibbāna.

**Files:** `sermons-graph.md` (the full graph, JSON embedded in markdown) + REPORT + MERGE-NOTES.
