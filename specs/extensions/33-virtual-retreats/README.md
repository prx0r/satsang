# 33 — Virtual retreats (real timetables + Dhamma audio + rules)

**What:** the retreat-at-home engine — pick a programme, get its daily
timetable, sit/walk/talk/meal blocks with a timer, Dhamma talks slotted
where the tradition puts them, the centre's rules presented up front, and
a completion record. Built from published schedules (structural facts) +
full-length talks (never clips, never remixed).

**Files:** VIRTUAL-RETREAT.md (engine spec), timetables/goenka-10day.json
(MBMC-published skeleton), DHARMA-SEED-RULES.md (CC BY-NC-ND compliance),
mcp-tools.json (start_retreat, retreat_today), REPORT + MERGE-NOTES.

**Honesty core:** a virtual retreat is orientation scaffolding, not
transmission. Initiation-gated practices stay out; teacher interviews are
replaced with "take this question to a teacher" prompts carrying the
teacher's contact; completion means you kept the schedule, nothing more.
