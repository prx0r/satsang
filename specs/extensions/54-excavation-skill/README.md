# 54 — Excavation skill (agent skill for sermon mining)

**What:** a skill for any agent to excavate a sermon (or any source text)
using the two-pass method: full extraction, verification against source,
hole hunting. Six validation gates. Output is raw material for compression,
not a script.

**The method:** Pass 1 extracts everything — metaphors, arguments,
refutations, definitions, scripture citations, cross-references, practical
instructions, the line worth keeping. Pass 2 re-reads the source against
the extraction to find misses. Pass 3 hunts for holes and connections to
other sermons.

**The gates:** Coverage, Organization, Fidelity, Argument integrity,
Utility, Honesty. All must pass before the excavation is done.

**Files:** `SKILL.md` (the skill) + REPORT + MERGE-NOTES.
