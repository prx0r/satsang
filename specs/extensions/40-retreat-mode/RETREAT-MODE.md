# RETREAT-MODE runtime (2026-10-20)

The device becomes the monastery. PWA first (installable, offline,
no app-store gatekeeper, open source); native guides second.

## Entering (commitment in, not just a toggle)

- Pick retreat (planned via 36) → set dates → write one-line intention →
  nominate accountability (buddy/cohort/teacher, or none) → ENTER.
- Entering starts: notification kill (Do Not Disturb profile + in-app),
  allowlist home screen (retreat app, timer, phone/messages-for-emergencies
  only — enforced by OS Focus/Digital Wellbeing profiles we configure,
  plus honest self-report where OS can't reach), grayscale nudge (optional).

## Discipline (the container holds)

- Block check-ins: each timetable block starts with one tap, ends with
  kept/skipped + one line. Skipped blocks stay visible (no silent drops).
- Noble-silence mode: messaging/social apps behind a break-glass screen
  ("state your reason in one line") — logged, never blocked (adults, not
  prisoners; the log IS the discipline).
- Rule acknowledgements: tradition + strictness rules signed at entry,
  re-shown on break (friction, not punishment).

## Consequences (real, proportionate)

- Broken blocks require a written reflection to resume the day (friction).
- Three broken days pauses the retreat: resume, restart, or close with
  notes (no shame copy; the log says what happened, plainly).
- Optional public commitment: cohort board shows kept/missed (no content
  of notes). Opt-in, off by default.
- Teacher review: share log with a teacher (their contact from the graph);
  nothing auto-sends, ever.

## Rewards (the keepsake economy)

- Day seals unlock keepsake sections (36-retreat-log): notes, stats,
  teacher prompts. The keepsake fills ONLY from kept practice — hollow
  days stay visibly hollow.
- Streaks + milestones are private by default; sharing publishes the
  curation path (05), never raw notes.
- Completion: export (JSON + printable page) + optional live-room
  graduation (35) with the cohort.

## Privacy (doctrine)

Local-first (IndexedDB): schedule, logs, notes never leave the device
except explicit export/share/sync (10-profile). No analytics on practice
content, ever. The platform cannot see your retreat.
