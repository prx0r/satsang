# 39 — Dharma sites registry (who hosts what, where the talks live)

**What:** the answer to "are they on each site like Amaravati" — a registry
of every major Dharma talk/retreat site with its hosting model, so the
player, the retreat builder and the clip pipeline know where to fetch.

**Two hosting models (that's the whole answer):**
- **Self-hosters** (Amaravati ~3,500 + podcasts + YouTube + AI transcripts;
  Abhayagiri retreat discs + Pasanno Archive with per-teacher consent DB;
  Birken library + YouTube + podcasts + Q&A directory; IMS talks page +
  Dharma Seed feeds; Metta Forest = dhammatalks itself).
- **Dharma Seed residents** (Gaia 4,500 talks, Spirit Rock 2,302-episode
  podcast, BCBS — subdomains gaia./sr./bcbs./imsrc.dharmaseed.org).

Plus Forest Sangha Publications (free ebooks hub) and Audiodharma.
