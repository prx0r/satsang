# 45 — VBT practices (safe dharanas, timer-native + interactive play)

**What:** six new VBT practice records derived from Hareesh's free
translation, plus a 7-day meditation-series collection chaining them in
the order the text itself presents them. Safe contemplative dharanas only:
no retention, no locks, no khecari, no mantra-given practices.

**Plus the interactive layer:** VBT-DOCTRINE.md (owner's verbatim voice
for how it should feel — play not meditation), VBT-INTERACTIVE.md (the
play system: TTS with timed pauses, sound-wave visuals, game-like
interaction), and a ready TTS script for sound-dissolution.

**The seven practices:** breath-pause (existing) → gap between thoughts →
inner sound → body as consciousness → inner/outer spaces → castle with
nothing inside → twelve centres throughout the day.

**Files:** `sources/vbt-practices/` (group with 6 practices) +
`collection-addition.json` (vbt-foundations series) +
`VBT-DOCTRINE.md` + `VBT-INTERACTIVE.md` +
