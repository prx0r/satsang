# RIGHTS — the copyright regime (2026-10-20)

*Not legal advice. Edge cases go to the owner; the report flow (05,
`wg_reports`) covers takedowns. This file is the rule agents follow.*

## 1. Licence taxonomy (editions)

| licence | meaning | link rule |
|---|---|---|
| `public-domain` | author dead 70+ years / pre-1929 publication | link verified free scans (archive.org, GRETIL, Wikisource) |
| `cc-*` | Creative Commons (BY, BY-SA, BY-NC…) | link; honour the variant (NC = non-commercial pages only) |
| `publisher-free` | publisher posts it free (DLS, dhammatalks, BPS) | link the publisher page, credit, never rehost |
| `permissioned` | explicit permission on file | link per its terms; terms live with the record |
| `copyrighted` | everything else by default | NO link except the official publisher/author page (navigation, not copy) |

Default is `copyrighted`. A freer licence must be evidenced, never assumed.
Translations are separate works: a PD original with a copyrighted translation
gets a citation-only record (title/author/publisher/year/ISBN — facts).

## 2. Text records

- Bibliographic facts are free: titles, authors, dates, publishers, ISBNs,
  tables of contents. Never copy: prefaces, introductions, translations,
  footnotes, cover art.
- Dharma Seed rule generalizes: where a licence says complete-and-unchanged
  (CC BY-NC-ND), we play/quote whole or not at all, credited, non-commercial.
- Link rot rule: a dead edition link demotes the record to citation-only
  until relinked (same doctrine as red flags).

## 3. Practice derivation (the practices programme)

| source | what we may write |
|---|---|
| Public-domain text | outline + short attributed excerpts; link the scan |
| Publisher-free teaching | outline in our own words; link the teaching |
| Copyrighted book/course | outline ONLY: structure, duration, safety, prerequisites — in our own words; teacher link + buy/official link; `needsTeacher` where the source requires it |
| Initiated/secret material | description-of-existence only: what it is, what lineage holds it, where to learn it. No steps. No mantras. |
| Living teacher's method | outline + teacher profile + place contact + their book/course link. The teacher's livelihood is the distribution channel, never bypassed. |

Mantras: traditional (PD) mantras may appear with source and pronunciation
guidance; teacher-given or initiatory mantras NEVER appear, not even
transliterated. Energy/initiatory practices always carry `needsTeacher` +
contraindications; the timer shows the caution above step 1.

## 4. Generated routines (structured syllabuses from materials)

Allowed: sequencing, timing, prerequisites, checkpoints, reflections,
progressions — all in our own words — with a source link on every step.
Forbidden: reproducing copyrighted instructions step-by-step, guided scripts
read from books, full translations, compilations that substitute for the book
(a routine must send the user TO the source, never replace it).
New field (proposed): `derivation: outline | summary | original` on Practice
and Collection, attested by the authoring agent, checked by rights-check-v1.

## 5. Enforcement

`rights-check-v1`: every text edition carries a taxonomy licence;
copyrighted editions carry no content link (official pages only); every
practice derived from a copyrighted source carries its source link +
derivation attestation; initiated material fails on ANY step detail.
FAIL = blocker. Reports of infringement skip the queue and page the owner.
