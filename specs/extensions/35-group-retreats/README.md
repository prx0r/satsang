# 35 — Group retreats (open-source live practice tech)

**What:** everything needed for one teacher to sit with many students
online — rooms, roles, cohorts, dana, consent — as open-source specs any
sangha can run, instead of each org reinventing Zoom links in spreadsheets.

**Landscape (studied, not forked):** Sangha Live runs the biggest version
(daily sits, Sunday Sangha, 4–6 week courses, dana-based, 100+ teachers);
Tergar runs the cohort version (self-paced + 5-week/6-month cohorts +
local communities + timezone restreams + translation). Borrow the shapes:
daily container, cohort spine, restream by timezone, dana not fees.

**Files:** GROUP-RETREATS.md (spec: roles, rooms, cohorts, dana, consent,
safeguarding), LEGALITY.md (the Burbea-jhana-retreat question answered),
mcp-tools.json (host_room, join_cohort), REPORT + MERGE-NOTES.

**Position:** solo virtual retreats (33) are self-serve and need no
permission; GROUP retreats need teacher opt-in always — the platform
lists, hosts and tracks, never enrolls a teacher or touches dana.
