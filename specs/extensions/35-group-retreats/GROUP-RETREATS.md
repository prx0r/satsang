# GROUP-RETREATS spec (2026-10-20)

Open-source live practice tech: one teacher, many students, zero lock-in.

## Roles

- **teacher**: owns the room, the recording policy, the dana link. Claims
  the room (verified identity + org link). Can mute, bring up hands, end.
- **host** (optional): runs tech/chat/timing so the teacher only teaches.
- **sit-leader**: opens daily sits (bell + timer, no teaching claim).
- **participant**: joins, sits, asks in Q&A windows. Progress stays theirs.

## Room layer (borrows 06 Gather, extends it)

1. **Today (no build):** join-links — teacher pastes their Zoom/Meet/Jitsi
   link per session; reminders carry it one-tap. This is what Sangha Live
   and Tergar effectively run today; support it first, it's enough.
2. **Native rooms (LiveKit, self-host or cloud):** sanctuary UI (33 timer +
   deitybody grammar visuals, bell, timer), low-bandwidth audio-only mode,
   timezone restreams (recorded teaching + live guides, Tergar pattern).
3. **Immersive (later):** WebXR room per GATHER-SPEC phase 3.

Audio posture: default everyone-muted; teacher + raised hands unmuted in
Q&A. No always-on gallery (retreat container, not meeting room).

## Cohorts (Tergar shape, open)

- **self-paced**: timetable + talks + timer, solo, anytime.
- **cohort**: same container, shared start date, discussion circle, guides.
  5-week and 6-month cadences; restreams per timezone with local guides.
- **local**: find-your-sangha from 32 places (same-tradition groups nearby).

## Scheduling + discovery

Sessions are 06-sessions rows (kind sit/circle/talk/qa/class) + 32
occurrences for dated retreats. Discovery: tradition/topic/teacher/country
filters + "live now" rail. Reminders T-10/T-1 per GATHER-SPEC.

## Dana (doctrine, not feature)

No fees on dharma. No platform cut. No held donations. Dana links point at
teacher/org only. Paid org products list with the org's terms and refund
policy mirrored, never rewritten.

## Consent + safeguarding (launch blockers)

Teacher opt-in in writing; recording policy announced per session;
safeguarding + minors policy + report flow before any open room; teacher
consent for any recording (see 05 reports table for violations).
